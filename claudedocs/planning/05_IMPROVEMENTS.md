## P1. 품질 개선

| # | 항목 | 내용 | 상태 |
|---|------|------|------|
| 1 | 네이티브 광고 칸 레이아웃 | 기본 템플릿이 3열 그리드 칸에 맞지 않음 → 커스텀 `NativeAdFactory` (Android/iOS 각각) | [ ] |
| 2 | 설정 화면 | 무음 촬영, 비율 자동 크롭, 격자선 표시, 정책 링크, 오픈소스 라이선스, 앱 버전 | [ ] |
| 3 | 비율 크롭 저장 | 가이드 프레임(레퍼런스 비율)과 실제 저장 사진 비율이 다름 → 저장 시 프레임 영역으로 크롭(Isolate) | [ ] |
| 4 | 무음 촬영 | 스트림 프레임 JPEG 변환. 해상도 저하 안내, 국가별 정책 검토 | [ ] |
| 5 | 투명도·마지막 프리셋 저장 | 앱 재시작 시 초기화됨 → `shared_preferences` | [ ] |
| 6 | 갤러리 열기 개선 | 갤러리 앱이 여러 개면 선택창이 뜸 → 앱 내 최근 사진 뷰어 + 공유 버튼 | [ ] |
| 7 | 레퍼런스 캡션 영역 | 레퍼런스 사진 하단 캡션 박스가 오버레이에 보임 → 교체 사진에서는 원본 사진만 사용 | [ ] |
| 8 | 좌우 반전 포즈 허용 | 레퍼런스와 좌우만 바뀐 자세도 일치로 볼지 옵션 (미러 매칭) | [ ] |
| 9 | 자동 촬영 옵션 | Perfect Match 0.5초 유지 시 자동 셔터 / 3초 카운트다운 | [ ] |
| 10 | 0.5배 왜곡 안내 | 전신샷에서 초광각 사용 시 가장자리 왜곡 → "1배 권장" 안내 | [ ] |
| 11 | 저조도·역광 안내 | 포즈 인식률 저하 원인 안내 (프레임 밝기 기반) | [ ] |
| 12 | 포즈 처리 성능 | 현재 메인 isolate에서 약 9fps. 발열·배터리 측정 후 필요 시 해상도/주기 조정 | [ ] |
| 13 | 서버 프리셋 캐시 | `GET /v1/presets` 응답을 로컬에 저장해 오프라인 재실행 시에도 최신 목록 사용 (ETag) | [ ] |
| 14 | 접근성 | 셔터·줌 버튼 Semantics는 적용, 스크린리더 실사용 점검 필요 | [ ] |
