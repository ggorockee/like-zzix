## 2. 높은 위험 (함께 고치는 것을 권장)

| # | 스토어 | 문제 | 해결 | 상태 |
|---|---|---|---|---|
| 1 | 공통 | 프리셋이 2개뿐 → "최소 기능 부족"(Apple 4.2) 지적 가능, 사용자 이탈 | 자체 제작 사진으로 6~8개 | [ ] |
| 2 | 공통 | 실제 인물로 판정 기준(10%/13%)을 검증하지 않음. "지금 찍으세요!"가 안 뜨면 핵심 기능 실패 | 실촬영 10회 이상, 지표 `perfect_match / preset_selected` 확인 | [ ] |
| 3 | 공통 | 첫 실행 권한 창이 닫히는 순간과 카메라 종료가 겹치면 로딩에서 멈출 수 있음 | 열기 작업이 끝난 뒤 전면 상태면 다시 열기 | [ ] |
| 4 | 공통 | 카메라 권한 거부 화면에 설정 이동 버튼이 없고 문구가 Android 기준 | 설정 열기 버튼, 플랫폼별 문구 | [ ] |
| 5 | 공통 | 글자 크기 2배에서 화면 넘침 (iPhone SE 하단 257px, 17 Pro 오른쪽 102px) | 글자 배율 상한 또는 줄바꿈 | [ ] |
| 6 | 공통 | 음료 프리셋 안내("컵은 입 근처까지")와 사진(턱을 괸 자세)이 다름, 컵 주변 외곽선이 지저분함 | 문구·외곽선 수정 | [ ] |
| 7 | iOS | 사진 "일부만 허용" 상태에서 앨범 생성이 실패할 수 있음 | 차단 4번 해결 시 함께 해소 | [ ] |
| 8 | iOS | 앱 기본 언어가 영어(`en`) → 스토어에 언어가 영어로 표시 | 개발 언어를 한국어로 | [ ] |
| 9 | iOS | 키워드의 "인스타"는 타사 상표 (Apple 2.3.7) | 키워드에서 제거 | [ ] |
| 10 | iOS | Crashlytics dSYM 업로드 단계가 없어 네이티브 크래시 위치를 알 수 없음 | 빌드 단계 추가 | [ ] |
| 11 | iOS | 앱 화면은 한국어뿐인데 174개국 출시 → EU 거래자(DSA) 신고·UMP 동의 부담 | 1.0은 대한민국만 출시 (권장) | [ ] |
| 12 | Android | Android 16 대화면(600dp 이상)은 세로 고정을 무시 → 각도 안내가 틀어짐 | 태블릿 제외 또는 가로 대응 | [ ] |
| 13 | Android | `READ_EXTERNAL_STORAGE`가 버전 제한 없이 병합됨 | 매니페스트에서 제거 또는 버전 제한 | [ ] |
| 14 | 공통 | 고객지원 페이지가 없는 "설정 화면"을 안내 | 정보 화면 추가 또는 문구 수정 | [ ] |
| 15 | Android | 어두운 환경·디버그 빌드에서 포즈 처리 1.1fps (이전 실측 약 9fps). 원인 미확정 | 밝은 곳·릴리스 빌드에서 재측정 | [ ] |
