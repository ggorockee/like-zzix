### 심사용 영상 (2~3분, 끊지 않고 한 번에)

조건: 실제 iPhone, 최신 iOS, 제출할 TestFlight 빌드, 앱을 지우고 새로 설치한 상태, 화면 기록 사용, 홈 화면에서 앱을 여는 장면부터 시작.

| 순서 | 보여 줄 것 |
|---|---|
| 1 | 홈 화면에서 라익찍스 실행 → 카메라 권한 허용 |
| 2 | 셔터 왼쪽 구도 버튼 → 추적 허용(ATT) 안내 → 목록 스크롤(광고 포함) → "중앙 배치" 선택 |
| 3 | 사람(또는 사람 사진)을 비춰 안내 문구가 바뀌는 모습 → 초록 테두리와 "완벽해요! 지금 찍으세요" |
| 4 | 촬영 → 사진 저장 권한 허용 → 갤러리에서 저장된 사진 확인 |
| 5 | 자물쇠 잠금 → 셔터와 배율만 남은 모습 → 길게 눌러 해제 |
| 6 | 다른 구도 하나 선택, 배율·렌즈 전환·화면 비율·자동 촬영 중 한두 개 |
| 7 | 오른쪽 위 앱 정보 → 개인정보처리방침과 고객지원 |

로그인·결제·사용자 게시물이 없으므로 해당 장면은 필요 없음.
